# BIBO — Personal Research Memory Agent

BIBO là dự án xây dựng trợ lý ghi nhớ và truy xuất tri thức nghiên cứu cá nhân. Giai đoạn hiện tại chỉ khởi tạo kho mã, môi trường Python và tài liệu yêu cầu; chưa có chức năng ứng dụng.

## Môi trường phát triển

Yêu cầu Conda và Python 3.11. Trên Windows, kích hoạt môi trường bằng:

```powershell
conda activate bibo
python --version
```

Nếu PowerShell chưa được cấu hình cho Conda, mở **Anaconda Prompt** rồi chạy cùng các lệnh trên.

Phạm vi, kiến trúc và lộ trình dự kiến được mô tả trong [PROJECT_REQUIREMENTS.txt](PROJECT_REQUIREMENTS.txt).
